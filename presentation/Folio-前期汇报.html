04 / 想实现的功能

围绕文档，完成三类具体工作。

填写

按用户的模板组织资料

从多份文件找到字段内容，综合项目经历，写回 Word 或 Excel，保留表格结构。

提取

把散落信息整理成可复用的数据

按用户指定字段提取人员、项目和培训信息，连同原文位置保存，供后续查询。

修改

用一句话提出内容与格式要求

替换文字、调整段落加粗与对齐；在同一对话中继续补充信息、修改上次结果。

05 / Agent 如何工作

从一句要求，到一个可以下载的文件。

读懂任务与模板

读取常用信息与偏好
分析文档结构和填写位置

→

跨资料寻找依据

搜索关键词、分页阅读
关联字段、原文地址与引用

→

调用工具生成文件

校验引用、局部写入
回读结果、生成来源报告

模型负责理解与组织

判断该找哪些资料，组织长文本字段；
需要时委派资料查证与模板审查子 Agent。

工具负责实际操作

读取、搜索、填写、提取、编辑与保存；
保护标签和公式，核对引用与写入结果。

06 / 工作台原型

在一个工作台里，交代任务、查看依据、继续处理。

核心交互

上传资料与模板
自然语言发起任务
查看文件和原文依据
补充缺项后继续处理

个人资料跨任务保留。
每次对话展示自己的要求、过程和生成文件。

07 / 技术栈与分工

前端工作台、Agent 运行时与文档工具。

交互界面

React 19 + TypeScript + Vite

资料与模板管理、持续对话、执行过程、文件预览和来源跳转。

应用服务

Python + FastAPI + Pydantic

异步任务 API、参数校验、状态与执行事件查询、文件上传和下载。

Agent 调度

Deep Agents + LangGraph

工具调用与按需委派，SQLite checkpoint 保存会话；兼容模型服务接入。

文档与存储

python-docx + openpyxl + SQLite

Word / Excel 解析与局部写回，文本读取；资料索引与报告入库，文件本地保存。

08 / 一次工作，如何延续到下一次

用同一份个人资料，完成不同的办公任务。

个人空间

简历.md

这次

填写员工登记表

根据模板整理个人信息，项目经历控制在 100 字以内。

接着

补充信息，继续原表

补齐联系方式，保留已经确认的内容，重新生成文件。

下次

整理项目申报资料

复用项目记录与个人信息，按新的字段和要求组织内容。

课设要实现的体验：资料持续积累，任务交代清楚，结果可以继续处理。
